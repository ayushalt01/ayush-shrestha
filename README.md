# BulkAI - AI Nutrition Coach for Healthy Weight Gain

BulkAI is a modern, responsive web application designed specifically for skinny guys who want to gain healthy weight. It combines personalized nutrition planning with AI-powered coaching to help users achieve their fitness goals.

## Features

### 🎯 Personalized Calorie Calculator
- Calculate daily calorie targets based on your body metrics
- Input weight, height, age, activity level, and goals
- Get precise macronutrient breakdowns (protein, carbs, fats)
- Science-based calculations using the Mifflin-St Jeor equation

### 🍽️ AI-Recommended Meals
- Get 5 complete meal suggestions per day
- Breakfast, snacks, lunch, and dinner recommendations
- Calorie information for each meal
- Practical, real-world food suggestions

### 💬 Ask BulkAI Chat
- 24/7 AI nutrition coach
- Get instant answers about:
  - Supplements and nutrition
  - Meal planning and food choices
  - Workout nutrition
  - Weight gain strategies
  - Budget-friendly options
  - Plant-based alternatives

### 📱 Responsive Design
- Beautiful gradient UI with motivational design
- Fully responsive for desktop, tablet, and mobile
- Smooth animations and transitions
- Clean, modern interface

## Getting Started

1. Open `index.html` in any modern web browser
2. Click "Get Started" or scroll to the calculator
3. Enter your body metrics and goals
4. Get your personalized nutrition plan
5. Ask BulkAI any questions about nutrition

## Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with gradients, animations, and responsive design
- **JavaScript** - Interactive functionality and AI chat logic

## How to Use

### Using the Calculator
1. Enter your current weight in kilograms
2. Enter your height in centimeters
3. Enter your age
4. Select your activity level
5. Choose your weekly weight gain goal
6. Click "Calculate My Plan"

### Using the Chat
1. Scroll to the "Ask BulkAI" section
2. Type your nutrition question
3. Press Enter or click Send
4. Get instant AI-powered advice
